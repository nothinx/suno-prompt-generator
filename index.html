01

Sumber gaya — link YouTube

Tool membaca metadata lagu referensi untuk menebak genre, mood, vokal & instrumen.

Mau deteksi komprehensif? Tanpa API key, YouTube hanya memberi judul + channel — itu sebabnya hasilnya sedikit. Dua cara memperkaya:
  1. Tempel deskripsi (tanpa API, instan): buka video → klik "…Selengkapnya" pada deskripsi → salin teksnya → tempel di kotak bawah sebelum menekan Scan gaya.
  2. Pakai API key untuk baca deskripsi + tags + kategori genre resmi otomatis (paling komprehensif) — panduan di bawah.
Cara dapat YouTube Data API key (gratis, ±5 menit)
  1. Buka Google Cloud Console, login, lalu buat / pilih sebuah project.
  2. Aktifkan API: buka YouTube Data API v3 → klik Enable.
  3. Buka Credentials → + Create Credentials → API key → salin key (bentuknya AIza…).
  4. Tempel key di bawah → Simpan. Key disimpan lokal di browser Anda saja.

Gratis: kuota 10.000 unit/hari (±10.000 lagu). Disarankan: di halaman Credentials, batasi key ke website nothinx.github.io/* dan ke API YouTube Data API v3 saja.
